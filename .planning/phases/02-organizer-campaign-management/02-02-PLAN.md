<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Authenticated request to Server Component | Cookies identify the requester before private campaign data is selected. |
| Server query to PostgREST/RLS | DTO selection crosses the tenant boundary and must not accept a browser-selected organization. |
| DTO to browser HTML | Only fields intended for the private campaign card are rendered. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-04 | Information disclosure | `listOwnerCampaigns` | high | mitigate | Require trusted user, accept no tenant parameter, rely on owner RLS, and prove two-owner isolation. |
| T-02-05 | Spoofing | Campaign detail links | medium | mitigate | Links carry only campaign UUID; the destination must reauthorize independently and map foreign IDs to neutral absence. |
| T-02-06 | Denial of service | Dashboard card rendering | low | accept | Owner-only data and bounded text fields limit exposure; pagination is not required by any Phase 2 source artifact. |
| T-02-SC | Tampering | Package supply chain | low | accept | This plan installs no package and leaves package manifests and lockfiles unchanged. |
</threat_model>

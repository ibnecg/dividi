<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Wizard to Server Actions | Untrusted campaign ID, content, key type, and key value cross from the browser. |
| Server Actions to owner RPCs | Authenticated identity and normalized values cross into database-owned authorization. |
| Campaign mutation to audit trigger | Sensitive recipient configuration creates retained evidence that must be safe and immutable. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-07 | Tampering | PIX recipient and content commands | high | mitigate | Strict selected-type validation, allow-listed RPC signatures, row locks, owner checks, and direct-DML denial. |
| T-02-08 | Repudiation | PIX recipient changes | high | mitigate | Same-transaction trigger events with database-derived actor and no client audit-write privilege. |
| T-02-09 | Information disclosure | Detail route and form errors | high | mitigate | Owner RLS, neutral not-found behavior, safe DTOs, and generic errors without raw database/key details. |
| T-02-10 | Spoofing | PIX syntax result | medium | mitigate | Label validation as format-only and make no ownership, registration, or bank-verification claim. |
| T-02-SC | Tampering | Package supply chain | low | accept | This plan installs no package and leaves package manifests and lockfiles unchanged. |
</threat_model>

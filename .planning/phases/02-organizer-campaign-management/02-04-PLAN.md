<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Item forms to Server Actions | Untrusted campaign/item IDs, text, quantity, and money strings cross from the browser. |
| Server Actions to item RPCs | Validated inputs cross into database ownership, locking, and immutable fulfillment rules. |
| Item rows to later public/donation consumers | Stored prices, quantities, and disable state become future payment and availability facts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-11 | Tampering | Quantity and unit price | high | mitigate | Parse exact bounded integers, enforce database checks, revoke direct DML, and test boundary neighbors. |
| T-02-12 | Elevation of privilege | Item RPC identifiers | high | mitigate | Derive caller identity, join item to owner campaign in each command, lock rows, and test foreign/anonymous denial. |
| T-02-13 | Tampering | Donation-linked item edits | high | mitigate | Database command rejects edits when confirmed quantity is positive and tests atomic non-mutation. |
| T-02-14 | Repudiation | Disable command retries | low | accept | Disable is idempotent and retained `disabled_at` plus row identity shows resulting state; item auditing is not a Phase 2 requirement. |
| T-02-SC | Tampering | Package supply chain | low | accept | This plan installs no package and leaves package manifests and lockfiles unchanged. |
</threat_model>

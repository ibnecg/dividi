## Trust Boundaries

| Boundary | Description |
|---|---|
| Authenticated JWT → Postgres RLS | Caller identity is interpreted by policies and security-definer functions. |
| Generated database schema → TypeScript callers | Drift can make application assumptions diverge from deployed grants/functions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-10 | Elevation of privilege | membership writes | critical | mitigate | Explicit table/function grants plus pgTAP denial for anonymous and authenticated direct DML. |
| T-01-11 | Information disclosure | organization RLS | high | mitigate | Two-owner fixtures prove own allow and foreign/anonymous empty results under application roles. |
| T-01-12 | Tampering | repeat/concurrent bootstrap | high | mitigate | Transaction advisory lock, unique user invariant, idempotent existing-row return, rollback assertions. |
| T-01-13 | Elevation of privilege | security-definer helpers | high | mitigate | Empty pinned search path, fully qualified relations, private helper schema, and privilege metadata assertions. |
| T-01-14 | Tampering | generated schema contract | medium | mitigate | Generate from reset migrations and require byte-identical regeneration plus TypeScript compile. |
| T-01-SC | Tampering | package tools | high | mitigate | Use only the approved project-local Supabase CLI pinned by Plan 01-01; no new package install. |
</threat_model>
